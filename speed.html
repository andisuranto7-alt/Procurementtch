SPEED Clone — replika baca-saja tampilan SPEED (speed.pttrimitra.com) untuk PT Trimitra Chitrahasta. Data dibaca langsung dari spreadsheet backend yang sama dengan DAILY PRO (tab LIVE_*) dan diperbarui otomatis tiap 60 detik. Halaman ini tidak terhubung ke SPEED asli: tidak ada login, input vendor, upload, atau submit — itu fase 2 yang membutuhkan server dan akun vendor. Bila sebuah tab gagal dimuat, bagian terkait menampilkan keterangan “data tidak tersedia” dan halaman lain tetap tampil.
